# 灵感菇 0.2.3 Beta / Release draft

首个公开候选版本，面向 macOS 14+ Apple Silicon。发布时应在 GitHub 勾选 **Pre-release**，推荐标签 `v0.2.3-beta.1`。

## 内容 / Included

透明蘑菇桌面组件、物理气泡、离线记录、五状态、用户标签、Markdown/JSON 导出、兼容 API 的整理/归纳/流式讨论、投资评估报告和持续讨论。

Local-first capture, physics widget, five workflow states, tags, exports, AI summaries/chat and read-only evaluation with linked discussions.
