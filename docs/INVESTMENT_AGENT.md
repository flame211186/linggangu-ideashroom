# 投资视角 Agent 使用指南

## 保存与继续讨论（0.2.1）

成功的评估会自动保存在本地；选中对应灵感，在“评估历史”中切换版本。
“保存报告…”可将当前版本完整导出为 Markdown 文件，包含原始灵感快照和评估依据。
点击“讨论此评估”进入关联对话，输入你的追问后才发送 API 请求。再次点击同一评估会继续已有会话；重启后也可从 AI 讨论的历史菜单找到它。
对话携带所选评估的固定快照及当前灵感，历史意见不是市场事实。重新评估不会覆盖旧会话。若已有未发送草稿，请先发送或清空。

这是原生内置的想法评估工具，不是股票交易或自动执行系统。

## 开始使用

1. 保存你的 API 设置并确认连接正常。无需再次提供密钥，也不要把密钥贴到聊天中。
2. 在工作台选中灵感，切换“投资 Agent”。选择当前灵感、多选、日期、标签或主题范围。
3. 点击评估，确认服务地址、数量和费用提示。归档记录不发送。
4. 查看评估历史、判断依据与最小验证实验，自行决定是否执行或改变状态。

可以在灵感正文补充你掌握的技能、每周可用时间、预算和能接触到的用户。未提供的信息会列为缺失证据，不应被理解为已调查过的事实。

## 如何理解结果

- 结论为立即验证、继续观察或暂时归档；不会替你归档或实施。
- 五项评分为 0—5；置信度是模型自报，不是成功概率。
- 正反理由和获客路径是待验证判断；当前版本不联网搜索，不提供真实市场调查。
- 候选清单每条取最新结果，排除已完成、归档、建议暂时归档及正文已变化的记录。
- 每次评估保存独立历史及原文快照、模型、Prompt 版本。正文变化后旧结果仍可查看，但会提示重新评估。

## 兼容性与安全

首版使用 OpenAI-compatible Chat Completions。厂商原生协议需要未来新增适配器，不能保证任意 API 或模型都支持。
结构化响应不受支持时会降级，解析失败最多重新生成一次；网络重试、降级和修复可能消耗更多 token。停止任务不保证服务端停止计费。
本地保存成功才显示新结果；失败可重试，已完成历史保留。评估数据随 JSON 导出，不包含 Provider 配置或密钥。
