# Contributing

LingGanGu is in its architecture-stabilization period.

## Current policy

- Bug reports, feature requests, usability observations, and reproducible test
  cases are welcome through GitHub Issues.
- External pull requests are not accepted before v1.
- Please do not send source-code patches by Issue, email, or another channel.

This policy keeps copyright and relicensing boundaries clear while the local data,
theme, AI provider, and Agent interfaces are still changing. A future contribution
policy may require a Contributor License Agreement.

## Security reports

Do not publish API keys, private notes, database files, or exploitable security
details in a public Issue. Follow [SECURITY.md](SECURITY.md).
