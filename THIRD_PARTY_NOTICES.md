# Dependency and artwork inventory — 0.2.3 Beta

The Swift package declares no external package dependencies. SwiftUI, AppKit,
Foundation, Security, Carbon and SpriteKit are system SDK/framework components;
SQLite is linked from macOS, not vendored into this repository. Their respective
platform terms apply. No framework source is copied into this project.

The project mushroom PNGs were supplied/selected by the project owner during
AI-assisted visual exploration. They are project artwork, not photographs of
users or their screens. This records provenance; it is not a guarantee of
exclusive copyright in AI-generated imagery. See TRADEMARKS.md for branding.

The idea-validator and DIALECTIC projects informed high-level evaluation concepts.
Their source and prompt files are not embedded or vendored. No Python agent runtime
or cloud account service is included. System fonts are referenced, not bundled.

All credentials in automated tests are deliberately fake. API service access is
provided by each user's chosen service under that service's own terms.
